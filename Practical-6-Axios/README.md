# Practical 6: React Axios API Fetch

## Aim
To fetch data from an API using Axios in React and display loading and error messages.

## Technologies Used
- React
- Axios
- Vite
- JSONPlaceholder API

## Features
- Fetches user data from an API.
- Displays user name, email, and city.
- Shows a loading message while fetching data.
- Handles API errors.
